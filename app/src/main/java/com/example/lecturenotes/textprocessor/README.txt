=== БЛОК: TextProcessor ===

ЧТО ДЕЛАЕТ:
- Заменяет голосовые команды на символы ("плюс" → "+", "точка" → ".")
- Вычисляет арифметические выражения ("2 + 3" → "2 + 3 (=5)")
- Обрабатывает "=" как триггер: "2 + 3 равно" → "2 + 3 = 5"
- Нормализует пунктуацию и пробелы

К ЧЕМУ ПОДКЛЮЧЕН:
- RecordingViewModel вызывает applyVoiceCommands() для live-чанков
- RecordingViewModel вызывает process() при финализации записи
- UI и ViewModel не знают о внутренней реализации (USB-принцип)

КОНТРАКТ TextProcessor (interface):
- process(rawText: String): String — полный pipeline
- applyVoiceCommands(text: String): String — только замена команд
- solveArithmetic(text: String): String — только вычисление
- voiceCommands: Map<String, String> — словарь команд

РЕАЛИЗАЦИЯ DefaultTextProcessor:
- Потокобезопасен (immutable state)
- Не зависит от Android (нет android.util.Log)
- Конструктор принимает кастомный словарь команд
- enableArithmetic = false отключает вычисления

ПАРСЕР АРИФМЕТИКИ:
- Recursive descent (безопасная замена eval)
- Поддерживает: + - * / ^ ( ) и унарный минус
- Приоритет: скобки → степень → умножение/деление → сложение/вычитание
- Деление на ноль → ArithmeticException → null → выражение не изменяется

ОГРАНИЧЕНИЯ:
- "корень из" не поддерживается (удалён из словаря)
- "процент" заменяется на "%" но не вычисляется
- 2^3^2 = 64 (левоассоциативность), не 512
